巴士鐘92

KMB BUS CLOCK

你的迷你巴士站。

插上 USB，幾步就用得。

  1. 安裝
  2. 連 Wi-Fi
  3. 揀巴士
01

安裝到裝置

電腦用 Chrome 或 Edge，USB 數據線接上巴士鐘。

只適用 E32R28T-1 · ST7789 · 2.8 吋

安裝會取代板上原有程式。更新本巴士鐘會保留設定。

02

連 Wi-Fi

選 2.4GHz 網絡。密碼只送到你的裝置。

03

揀巴士，出發。

首次使用按屏幕上的三個十字。

屏幕齒輪 → 巴士 → 路線 → 方向 → 上車站 → 儲存。

日後換網絡：齒輪 → 裝置 → Wi-Fi。

連唔到／安裝失敗？
  • 換一條可傳資料的 USB 線，關閉其他串口或設定工具。
  • 首次電腦安裝用 Chrome／Edge；iPhone 用裝置屏幕設定 Wi-Fi。
  • 連接停住：按住 BOOT、按一下 RESET，再放開 BOOT，重新安裝。
  • 裝到一半失敗可重試同一頁；不要拔線直至完成。
  • 如果電腦完全看不到串口，測試板使用 CH340；Windows 可取用 WCH 原廠驅動，詳見 安裝說明。
